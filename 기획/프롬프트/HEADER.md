## 열려 있는 결정

- **반·이름** (파일명) — 사용자 확인
- **발표자료 형식** — 사용자가 추후 결정
- 수평 판정 허용 범위 `LEVEL_TOLERANCE_DEG = 2.0` — 센서 측정 후
- 회전(θ)을 센서 yaw 로 받을지 — 정지 3분 밀림 ≤ 3° 그리고 되돌아오기 ≤ 2°
- LLM 이 성공하면 화면·문서·발표의 `AI 미연결` 표현을 어떻게 바꿀지

## 지켜야 할 규칙

- **구현하지 않은 것을 구현했다고 쓰지 않는다.** 설계만 한 것은 `[설계]` 로 표시한다
- 검증하지 않은 수치(정확도 %, 시간 절감 % 등)를 쓰지 않는다
- **허용 오차는 교육 과정 설정값이며 실제 장비의 정렬 정밀도가 아니다**
- **"실장비 대체"라고 쓰지 않는다.** 투입 전 판단 훈련이다
- 규칙 기반 채점을 AI 채점이라고 부르지 않는다
- 제출물의 필드·코드는 실제 서버와 대조한 것만 쓴다
- 설치·서버 실행은 한 세션만 한다
- git commit/push 는 사용자가 직접 한다 (사용자가 요청하면 HEADER 가 한다)
