# data — WME 센서 측정 기록

2026-09-13: 기록·분석 도구 작성. **실측 데이터와 드리프트 결과는 아직 없음(미측정).**
합성 검증 자료와 실측 자료를 섞지 않는다. 센서 펌웨어·배선 조건·단계별 측정 설명은 `../hardware/README.md`를 따른다.

## 실행 순서 (프로젝트 루트의 Mac 터미널)

센서 스케치를 업로드하고 정상 출력 확인 후, IDE 시리얼 모니터/플로터와 브라우저 시리얼 연결을 닫는다.
모형을 평평한 책상에 놓고 아래 명령을 시작한 뒤 완료까지 손대지 않는다.

```bash
python3 data/capture_drift.py --port /dev/cu.usbmodem1101
python3 data/analyze_drift.py data/raw/drift_2026-09-13.csv
```

- `capture_drift.py`: Python 표준 라이브러리만 사용하는 **macOS 전용** 시리얼 기록 도구.
  115200 baud, 첫 정상 샘플 후 30초 안정화, 보드 시간으로 60초 기록. 약 90~95초 소요.
- `analyze_drift.py`: 운영체제에 관계없이 Python 3로 실행. roll/pitch 최대-최소와 yaw 끝-시작을 계산.
- `raw/drift_2026-09-13.csv`: 사용자가 실제 수집할 때 생성. 헤더 없이 `WME,t_ms,roll,pitch,yaw` 줄 그대로 저장.
- `raw/drift_2026-09-13.txt`: 사람이 실제 수집 조건(시각·고정 방향·접촉·정지 여부·안정화 시간)을 함께 기록.
- 기존 CSV는 덮어쓰지 않음. 재측정은 `--output data/raw/drift_2026-09-13_repeat2.csv`처럼 새 파일 사용.
- Ctrl+C/통신 오류로 남은 파일은 부분 기록. 분석기가 거부하거나 측정 중 움직였다면 완료 결과로 보고하지 않는다.

## 판정

`abs(yaw 끝값 - 시작값) > 1.00°` → 회전은 화면 버튼. 음수 방향 밀림도 동일하다.
정확히 ±1.00°는 초과가 아니다. 기준 이내면 이번 정지 드리프트 기준 충족으로 HEADER에 전달한다.
기록 길이 60.000~60.100초, 시각 증가, 평균 45~55Hz, 최대 간격 100ms 이하를 확인하며 손상·짧은 기록은 판정하지 않는다.
이 수집 품질 검사는 목표 전송 규격 50Hz를 대체하지 않는다. 자동 재영점/보간으로 실측 오차를 숨기지 않는다.

기계가 읽을 결과가 필요하면 다음과 같이 실행한다.

```bash
python3 data/analyze_drift.py data/raw/drift_2026-09-13.csv --json
```

## 기존 폴더 경계

| 폴더 | 취급 |
|---|---|
| `raw/` | 실측 기록. 이번 정지 드리프트 파일의 저장 위치 |
| `raw/train_normal/`, `raw/validation/`, `raw/test/` | 이전 계획의 자리 유지. 이번 정렬 실습은 모델 학습 없이 드리프트 측정 |
| `demo/` | 표시된 재생 데이터용. 실측으로 오인하게 만들지 않음 |
| `models/` | 기존 자리 유지. 이번에 모델을 만들지 않음 |
| `local/` | **BACK 담당. 읽기·쓰기·테스트 대상에서 제외** |

드리프트 결과는 `hardware/README.md`의 미측정 표에 실제 측정 후 기록한다.
기울임 부호 확인은 별도 절차이며, 드리프트를 기록하는 1분 동안은 움직이지 않는다.
