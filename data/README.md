# data — 측정 기록과 모델

데이터의 출처를 섞지 않는 것이 이 폴더의 존재 이유다.
화면에서도 `예시 데이터 / 저장된 측정 재생 / 실시간 모형 측정` 을 항상 구분해 표시한다.

| 폴더 | 내용 | 규칙 |
|---|---|---|
| `raw/train_normal/` | 학습용 정상 세션 | 같은 부착·관측 조건에서만 수집 |
| `raw/validation/` | 임계값 조정용 세션 | 학습에 쓴 세션과 겹치지 않게 |
| `raw/test/` | 최종 확인용 세션 | 조정에도 쓰지 않음 |
| `demo/` | 발표용 재생 데이터 | 실측이 실패했을 때의 표시된 대체 수단 |
| `models/` | 모델 파일 · 특징 설정 · 임계값 · 데이터 목록 · 버전 | 버전 없는 모델 파일을 두지 않음 |
| `local/` | 개발용 SQLite DB | 제출물에 포함하지 않음 |

## 지키는 것

- 한 기록의 겹치는 시간 창을 무작위로 나눠 "독립 검증"이라고 하지 않는다.
- 학생 실습 데이터를 정상 학습 데이터에 자동으로 넣지 않는다.
- 세션마다 수집 조건(부착 상태, 동작 방식, 날짜)을 같은 이름의 `.txt` 로 남긴다.

**현재 상태: 비어 있음.** 센서 확보 전이다.
