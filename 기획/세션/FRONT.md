# FRONT 세션 프롬프트 — 화면

---

한국어로 답해줘. 나는 코딩 경험이 거의 없는 SKALA 교육생이고, 3일짜리 AI 웹서비스 미니 프로젝트를 하는 중이야. 이 대화는 **FRONT 세션**이야. 화면만 담당해.

## 시작 전에 읽을 것

1. `PROJECT_HEAD.md` — 제품 정의, 확정된 결정, 지켜야 할 원칙
2. `기획/PROGRESS.md` — 완료·진행 중·다음 작업
3. `기획/세션/README.md` — 세션별 담당 폴더

## 내 담당

**쓰기**: `web/frontend/`
**읽기만**: `기획/설계/`, 나머지 전부

## 지금 상태

- React + Vite + TypeScript + Tailwind v4 + Recharts + React Router
- 화면 11개 구현됨(로그인 → 실습 목록 → 대기방 → 연습). 시드 데이터로 동작. 타입 검사·빌드·린트 통과
- 화면 용어는 **신입사원 / 매니저**. 데모 로그인 `1`/`1`, `2`/`2`
- **센서, 백엔드, LLM은 아직 없다.** 화면이 그것들에 연결된 것처럼 보이게 만들지 않는다

```bash
npm --prefix web/frontend run dev      # http://localhost:5173
npm --prefix web/frontend run build    # 타입 검사 + 빌드
npm --prefix web/frontend run lint
```

## 다음 작업: 연습 화면(`/attempts/new`) 알맹이 채우기

`src/sensor/` 폴더가 아직 비어 있다. 지금은 배치만 잡힌 골격이다. 센서 없이도 아래를 전부 만들 수 있다.

1. **mock 센서 어댑터** — `src/sensor/` 에 `SensorSource` 인터페이스와 `MockSource`.
   초당 약 50회 샘플을 합성한다. 정상 구간과 "정지 후에도 흔들림이 남는" 이상 구간을 모두
   만들 수 있어야 한다. 나중에 `ReplaySource`(저장 파일 재생)와 `LiveSource`(WebSocket)를
   같은 인터페이스로 끼울 수 있게 설계할 것
2. **실시간 차트** — 기준(정상) 기록과 현재 측정을 같은 시간축에 겹쳐 표시
3. **동작 단계 버튼** — 측정 시작 / 동작 종료 / 측정 종료. 자동 구간 인식은 만들지 않는다
4. **이상 후보 구간 표시** — 동작 종료 이후 안정화 구간만 대상. 정상 기록 대비 통계 비교로 계산
5. **근거 구간 선택** — 후보 구간 클릭 또는 차트 드래그로 선택
6. **답변 제출** — 근거 구간 + 점검 항목 + 이유 → 새 attempt 로 저장 → `/attempts/:id/result` 이동.
   저장은 localStorage 를 쓰되 **`src/api/index.ts` 함수 안에서만** 처리한다
   (나중에 BACK 세션이 이 함수 본문을 `fetch` 로 바꾼다)

## 반드시 지킬 것

- **데이터 출처를 항상 표시한다.** 합성 데이터는 `예시 데이터` 배지를 달고 실측처럼 보이게 하지 않는다
- 업종·고객사 문구는 `src/data/tenant.ts`, `src/data/courses.ts` 에만 둔다.
  컴포넌트에 "반도체", "웨이퍼" 같은 단어를 직접 쓰지 않는다
- **이상도는 상대적 근거이지 고장 확률이 아니다.** 원인을 단정하는 문구를 쓰지 않는다
- **판단은 학습자가 한다.** AI가 정답을 내려주는 화면으로 만들지 않는다
- 재실습은 새 기록으로 저장하고 이전 기록을 지우지 않는다
- 진도(얼마나 했나)와 달성도(기준을 얼마나 충족했나)를 섞지 않는다
- 차트는 `src/charts/theme.ts` 의 색과 규칙을 따른다. 색만으로 뜻을 싣지 않고 범례·값 라벨을 함께 둔다
- `src/api/index.ts` 의 함수 시그니처는 REST 명세와 1:1이다. 마음대로 바꾸지 않는다
- 한 번에 다 만들지 말고 단계별로 만들고 화면으로 확인한다. **확인한 것만 완료라고 말한다**
- 작업이 끝나면 `기획/PROGRESS.md` 를 갱신한다

시작하기 전에 무엇을 어떤 순서로 할지 짧게 말하고 시작해줘.
