## 확정된 규격 (바꾸지 않는다. 바꾸면 화면이 값을 못 읽는다)

**데이터 경로**: 아두이노 → USB 시리얼 → 브라우저(Web Serial API). **서버를 안 거친다.**

**조작 매핑** — 접촉식 마스크 얼라이너에는 노광 전에 마스크와 웨이퍼를 평행하게
맞추는 단계가 실제로 있다. 그래서 실제 순서인 "평행 → 회전·위치"를 그대로 쓴다.

```
모형 기울기 (roll/pitch) → 수평(평행) 맞추기. 0 에 가까워져야 한다
모형 비틀기 (yaw)        → 회전 θ          ← yaw 가 주 입력이다
X/Y 위치                 → 키보드 방향키
```

**시리얼 출력 형식**

```
WME,<t_ms>,<roll>,<pitch>,<yaw>\n      예) WME,1240,-3.25,7.81,0.42
```

- 한 줄에 한 샘플 / `t_ms` 는 경과 밀리초(정수) / 각도는 도(°), 소수점 둘째 자리
- **접두사 `WME,` 필수** — 부팅 메시지를 브라우저가 걸러내기 위한 것
- baud **115200**, 전송 주기 **초당 50회**
- roll/pitch 는 보드에서 계산(가속도계 + atan2), yaw 는 자이로 z축 적분
- 라이브러리 설치 없이 `Wire.h` 만 사용

## 남은 일

- [ ] **pitch 60° 원인 규명** — 평평하게 놓았는데 60°가 나온다면
      (가) 센서가 실제로 세워져 있거나 (나) 계산식의 축이 틀렸다.
      `ax/ay/az` 원시값을 함께 출력해 가려낸다. 평평하면 `az`가 1g, `ax·ay`는 0 근처여야 한다
- [ ] **정지 드리프트** — 안정화 30초 → 기록 3분.
      roll/pitch 흔들림 폭, **yaw 밀림을 1분 시점과 3분 시점 둘 다**
- [ ] **회전 되돌아오기 시험** ★ 진짜 판정 ★ — 약 90° 비틀었다 제자리로 되돌리고
      남은 yaw를 읽는다. 양방향 3회씩, 총 6회. 절댓값 최댓값을 보고한다
      (자이로 적분 오차는 정지 상태보다 움직일 때 훨씬 빨리 쌓인다)
- [ ] **부호 확인** — 왼쪽을 낮췄을 때 roll 부호 / 앞쪽을 낮췄을 때 pitch 부호 /
      시계 방향으로 비틀 때 yaw 부호. **모형에 고정한 뒤 다시 확인한다**
- [ ] 웨이퍼 모형 조립 — 센서를 판에 단단히 고정, 케이블 여유, 축 방향 표시

## 판정 기준 (HEADER가 판단한다. 숫자만 보고한다)

회전(yaw)을 센서 입력으로 쓰려면 **둘 다** 만족해야 한다.

1. 정지 3분 밀림 ≤ **3°**
2. 되돌아오기 시험에서 남은 값의 최댓값 ≤ **2°**

하나라도 못 넘으면 회전은 화면 버튼으로 간다. 실습의 회전 허용 오차가 ±1.0°라서,
입력 자체가 그보다 크게 틀어지면 학습자가 아무리 잘해도 맞출 수 없다.

수평 판정 허용 범위(지금 임시 ±2.0°)는 roll/pitch 흔들림 폭을 보고 HEADER가 정한다.

## 지켜야 할 규칙

- **측정하지 않은 숫자를 적지 않는다.** 못 한 건 "미측정"이라고 적는다
- 판정은 HEADER가 한다. 숫자를 그대로 보고한다
- **센서를 붙인 웨이퍼 모형은 실제 장비의 조작기를 대신하는 교육용 컨트롤러다.**
  실제 공정에서 웨이퍼를 손으로 기울여 정렬한다는 뜻이 아니다. 문서에 그렇게 적는다
- 센서가 없어도 키보드로 실습 전체가 된다. 센서는 가점이지 필수가 아니다
- 끝나면 `기획/작업로그/Sensor.md` 맨 위에 기록. git commit 은 하지 않는다
