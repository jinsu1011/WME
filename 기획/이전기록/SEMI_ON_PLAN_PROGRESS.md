# SEMI:ON 계획서 작성 진행 기록

## 목표
B2B 사내 반도체 기술교육 플랫폼을 기획하고, 웨이퍼 스테이지 이상 대응 실습 한 과정을 센서와 연결하는 3일 MVP의 전체 계획서를 작성한다. 실제 구현이 아니라 기획 문서 작성 요청이다.

## 확정된 사용자 방향
- 서비스의 핵심은 기업이 도입하는 사내 기술교육이다. 설비 관제 SaaS나 작업자 손동작 평가로 되돌리지 않는다.
- 과정 카탈로그는 여러 개로 구성하되 실제 실습 구현은 웨이퍼 모형 하나를 사용하는 한 과정에 집중한다.
- 정상 측정 데이터를 사전에 준비해 이상 탐지를 시연한다. 정상 기준 비교와 실제 모델 학습을 구분한다.
- Front-End 중심: 과정 탐색 → 개념 학습 → 센서 실습 → 학습자 판단 → 피드백 → 기록/교육 담당자 확인.
- 공지의 자율 작업 시간은 Day 1 6h, Day 2 8h, Day 3 제출까지 4h, 합계 18h. 기획·설계·문서 작업도 포함한다.
