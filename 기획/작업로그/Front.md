## 2026-09-14 밤 — 센서 모드 흐름 다시 잡기: 비튼 만큼 회전 · 정렬 5초 유지 → 실습 성공 · X/Y '고정' 표시

사용자 실물 확인 후 지적 3건.
1. X/Y 가 가운데 고정인데 초록 `기준 안` 으로 떠서 "맞춘 것"처럼 보였다
2. 수평만 맞춰도 초록 성공이 떴다 → **정렬 시작 뒤, 정렬된 상태를 5초 유지했을 때만** 성공을 띄워야 한다
3. 패널 원판은 비트는 대로 도는데 3D 웨이퍼는 안 돌았다

바꾼 것:
- **회전(센서 모드)**: 비틀기 → 속도 방식을 버리고 **비튼 각도를 그대로 따른다.**
  θ = 시작 오차 + (지금 비틀기 − 기준 비틀기) + 미세조정. 기준은 정렬 시작·영점 변경 때 다시 잡아 θ 가 튀지 않는다.
  **수평 잠금을 없앴다**(기울어져 있어도 돈다). 수평은 성공 조건으로 옮겼다. Q/E·±0.5° 버튼은 미세조정으로 남김.
  비틀기 속도 계수(`yawGainDegPerDeg` 등 course.control)는 센서 모드에서 더 이상 쓰지 않는다
- **실습 성공**: 정렬 시작 뒤 **수평(±4°) + 정렬 허용 오차 안(과정 설정 ±4px/±1°)** 을 `SUCCESS_HOLD_MS` 5초 끊김 없이 유지.
  벗어나면 0 부터 다시. 장비 뷰 아래에 진행 막대(`3.8 / 5초`) → 성공 시 초록 테두리 + 3초 깜빡임 + `실습 성공`·`정렬 유지 완료` 문구,
  3D 는 유지하는 동안 링이 조금씩 물들고 성공 순간 링 깜빡임 + 마스크 내려옴. 키보드 모드도 같은 규칙으로 성공이 뜬다
- 수평만으로는 초록이 되지 않게: 1단계 카드의 5초 진행 막대 제거, 수평은 작은 `수평` 배지만. 2단계는 `잠김` 대신 회전 오차 `기준 안/조정 중`
- **X/Y 표시**: `ErrorReadout` 에 `positionFixed` — 센서 모드는 회색 숫자 + `고정`, 요약 줄은 회전 오차와 "위치는 가운데 고정"
- `TiltSource` 는 수평을 즉시 판정(holdMs 0). 5초 유지는 실습 루프에서 센다
- 설정·문구: `LEVEL_HOLD_MS`/`LEVEL_RELEASE_DEG` 제거, `SUCCESS_HOLD_MS`·`SUCCESS_TEXT` 추가

## 2026-09-14 밤 — "The port is already open" 연결 오류

사용자가 실물 연결 중 `연결하지 못했습니다: Failed to execute 'open' on 'SerialPort': The port is already open.` 을 반복해서 봤다.

- **원인**: 실습 화면이 새로고침 없이 다시 그려지면(화면 이동, 코드 수정 반영) `TiltSource` 가 새로 만들어지는데,
  이전 것이 포트를 연 채 남아 있었다. 새 것이 같은 포트를 또 열려다 막혔다. 다른 탭이 포트를 잡고 있어도 같은 오류가 난다
- **수정**
  - 실습 화면을 떠나면 포트를 닫는다(`AlignmentExercise` 언마운트 정리)
  - 연결할 때 같은 페이지에서 포트를 잡고 있는 이전 컨트롤러(`TiltSource.active`)를 먼저 닫는다
  - 그래도 이미 열려 있으면(다른 탭·아두이노 IDE) 원문 대신 "다른 탭이나 시리얼 모니터를 닫고 새로고침" 안내를 보여 준다

확인한 것(브라우저, 보드 없이): 센서 모드 연결 상태(`connected`)에서 실습 화면을 떠나면 이전 컨트롤러가 `idle` 로 닫힘 →
다시 들어오면 새 컨트롤러가 `idle` 로 만들어지고 연결 버튼이 보임. 콘솔 오류 없음. 타입 검사·빌드·린트 통과(기존 경고 1건).
확인 못 한 것: **실물 포트로 "already open" 이 사라지는지는 보드가 없어 직접 재현하지 못했다.**

## 2026-09-14 — 정렬 결과를 눈으로 확인하는 노광·현상 연출

"마크만 겹치고 끝나서 정렬이 왜 중요한지 안 보인다"는 지적을 받고 만들었다.
**정렬을 확정하면 실제 공정 순서대로 노광 → 현상 → 패턴 확인을 보여 준다.**

- 노광: 마스크 너머로 빛을 쬐는 단계. 번쩍이지 않게 마스크 판이 잠깐 또렷해지는 정도로만
- 현상: **노즐에서 현상액이 위에서 떨어지고**, 닿은 자리에서 가장자리로 퍼진다.
  지나간 자리부터 패턴이 드러난다. 액 방울은 불투명 물체로, 퍼지는 액은 웨이퍼 표면에 직접 그린다
  (투명 평면은 다른 물체에 가려 보이지 않았다)
- 결과: **웨이퍼에 패턴이 남는다. 확정한 정렬 오차만큼 웨이퍼 마크에서 벗어난 자리에 찍힌다**
- 단계마다 무슨 일이 일어나는지 문장으로 함께 설명하고, 결과에는 통과 여부 배지를 붙인다
- '다시 조정하기' / '처음부터 다시' 를 누르면 연출이 지워지고 조정 상태로 돌아간다

구현에서 바꾼 것: 처음에는 패턴을 별도 평면으로 웨이퍼 위에 띄웠는데 화면에 보이지 않았다
(투명 객체 정렬·가림 문제로 보인다). **웨이퍼 표면 텍스처에 직접 새기는 방식**으로 바꿨다.
가려짐 문제가 사라지고, 패턴이 웨이퍼와 함께 움직이는 것도 자연스러워졌다.
연출 시간은 프레임 수가 아니라 실제 경과 시간으로 진행한다(연출은 물리 계산이 아니다).

확인한 것(브라우저):
- 노광(1.0초) → **액이 위에서 떨어짐(0.8초)** → 퍼지며 패턴이 드러남(1.4초) → 결과
