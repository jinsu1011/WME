## 2026-09-13 — 센서 연결(Web Serial) + 센서 모드 2단계 조작

- **Web Serial 연결** (`src/input/serial.ts`, `TiltSource.ts`): 연결 버튼 → `navigator.serial.requestPort()`
  → 115200 baud 로 열고 줄 단위로 읽는다. `WME,` 로 시작하는 줄만 쓰고(부팅 메시지는 버린다),
  조각이 잘려 와도 `LineBuffer` 가 이어 붙인다(버퍼 상한 8KB).
  상태: `unsupported / idle / connecting / connected / error` 를 화면에 그대로 표시하고,
  포트 미선택·연결 끊김·브라우저 미지원을 각각 다른 문장으로 안내한다.
  **언제든 '키보드로 진행' 버튼으로 되돌아간다.**
- **조작 방식 변경(센서 모드만)**: 기울기(roll/pitch)는 이제 이동을 만들지 않는다.
  기울기 → **수평(평행) 맞추기**, 비틀기(yaw) → **회전 θ(속도)**, X/Y → **키보드 방향키**.
  키보드 모드는 한 줄도 바꾸지 않았다.
- **2단계 흐름**: 1단계 수평 맞추기(현재 기울기 숫자 + 허용 ±2.0° + 평행 확보를 색·링·문장으로 함께 표시),
  2단계 회전(수평이 확보된 동안에만 yaw 가 θ 에 반영된다. 깨지면 잠기고 "먼저 수평을 맞추세요" 표시).
  회전 미세조정 버튼(−0.5° / +0.5°)은 yaw 드리프트 확인 전까지 백업으로 남겼다.
- **영점**: '영점 잡기' 버튼으로 현재 자세를 0 으로 삼고 이후 상대값으로 해석한다.
  '영점: 잡음 / 안 잡음' 을 화면에 표시하고, 지우기도 가능하다.
- **3D 컨트롤러 패널** (`components/ControllerPanel.tsx`): 3D 라이브러리 없이 CSS
  `rotateX(pitch) rotateY(roll) rotateZ(yaw)` 로만 그린다. 원판 + 축 표시 + 앞 방향 표식.
  수평이면 패널 테두리·배지·문장이 함께 바뀐다. 라벨은 "교육용 컨트롤러 상태 — 센서를 붙인
  웨이퍼 모형의 자세입니다."
  **정렬 화면의 마크는 3D 로 기울이지 않는다.** 정렬은 평면에서 X/Y/θ 로만 일어난다.
- 수평 허용값은 `src/data/controllerSettings.ts` 에 상수로 두고 **⚠️ HEADER 확인 필요** 주석을 달았다.
  서버 과정 설정에 자리가 생기면 그쪽으로 옮긴다. 시작값 ±2.0°.

확인한 것(실제 화면, 센서 없이 검증):
- 파싱·버퍼 — 부팅 메시지 무시 / `WME,1260,-3.1` + `0,7.60,0.44` 로 잘려 온 줄 정상 복원 /
  형식 오류 줄 거름 (실제 모듈을 브라우저에서 불러 확인).
- 영점 — 기울어진 자세(-5.2°, +6.4°)에서 영점 잡기 → 같은 자세가 +0.1°, +0.0° 로 읽히고 '평행 확보'.

브라우저에서 **두 모드 모두** 돌려서 확인한 것만 적는다.

  `/api` 와 `/ws` 를 8000 으로 넘긴다(같은 출처). 백엔드는 건드리지 않았고 포트 제약도 사라졌다.

  화면 문구는 그대로 "키보드 조작 / 모형 컨트롤러".
