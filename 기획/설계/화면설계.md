# 화면 설계

> 작성 예정. 아래 목차와 구현된 화면 목록만 잡아둔 상태다.
> 실제 화면은 `web/frontend/src/pages` 에 구현돼 있으므로, 문서는 구현을 따라 적는다.

## 1. 화면 목록

| 경로 | 사용자 | 화면 | 구현 |
|---|---|---|---|
| `/learn` | 교육생 | 학습 대시보드 | 완료 |
| `/learn/courses` | 교육생 | 과정 카탈로그 | 완료 |
| `/learn/records` | 교육생 | 실습 기록 | 완료 |
| `/courses/:id` | 교육생 | 과정 상세 | 완료 |
| `/attempts/new` | 교육생 | 실습 | 골격 |
| `/attempts/:id/result` | 공통 | 학습 결과 | 완료 |
| `/instructor` | 담당자 | 교육 현황 | 완료 |
| `/instructor/learners` | 담당자 | 학습자 목록 | 완료 |
| `/instructor/learners/:id` | 담당자 | 개인별 성취도 | 완료 |

## 2. 화면별 상세

각 화면마다: 목적 / 구성 요소 / 데이터 출처 / 사용자 동작 / 상태(로딩·비어 있음·오류) / 다음 화면.

- [ ] 학습 대시보드
- [ ] 과정 카탈로그
- [ ] 실습 기록
- [ ] 과정 상세
- [ ] 실습
- [ ] 학습 결과
- [ ] 교육 현황
- [ ] 학습자 목록
- [ ] 개인별 성취도

## 3. 공통 규칙

- [ ] 데이터 출처 배지 (예시 / 재생 / 실시간)
- [ ] 과정 공개 상태 배지 (실습 가능 / 미리보기 / 준비 중)
- [ ] 진도와 달성도의 구분
- [ ] 그래프 색·라벨 규칙
- [ ] 역할 전환은 인증이 아님을 표시

## 4. 화면 흐름도

- [ ] 교육생 흐름: 카탈로그 → 과정 상세 → 실습 → 결과 → 재실습
- [ ] 담당자 흐름: 교육 현황 → 학습자 → 개인 성취도 → 제출 답변
