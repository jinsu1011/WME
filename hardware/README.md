# hardware — 실습 장치

## 상태

**부품 미확보.** 보드 모델, MPU6050 보유 여부, 핀헤더 납땜 필요 여부가 아직 확인되지 않았다.
확인 전까지 핀 단위 배선 지침을 확정하지 않는다.

## 준비물 (계획)

| 준비물 | 수량 | 목적 |
|---|---:|---|
| Arduino 또는 ESP32 | 1 | 측정·전송 |
| MPU6050(GY-521) 모듈 | 1 | 3축 가속도 + 3축 자이로 |
| USB 데이터 케이블 | 1 | 전원·노트북 연결 |
| 점퍼선 | 4가닥 | VCC · GND · SCL · SDA |
| 작은 판 · 원형 모형 · 고정 재료 | 1식 | 실습 장치 |

## 배선

보드와 모듈의 동작 전압을 확인한 뒤 확정한다. 기본 연결은 VCC / GND / SCL / SDA 네 가닥이다.

## firmware/

Arduino 스케치 위치. 아직 비어 있다.

측정값을 시리얼로 내보내는 최소 스케치부터 만든다: 시간(ms), ax, ay, az, gx, gy, gz.
